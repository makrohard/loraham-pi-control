High-power +20 dBm permission (SX127x)

Allow POWER=20 on a radio. Default off; the radio's daemon must be restarted for a change to take effect, and a running daemon keeps the permission it was started with. At +20 dBm the transmit duty cycle must not exceed 1 % (SX1276/7/8 datasheet §5.4.3), the antenna VSWR must stay ≤ 3:1, and the chip needs suitable supply and cooling. LHPC does not measure or enforce the duty cycle. Outside-spec operation can damage hardware — warranty void if disregarded. Unvalidated on the LoRaHAM 433 RFM98PW: its module documentation does not specify this drive condition. No effect on an SX1262.
